# [Showvey v2.3 릴리즈 노트]

---

### 1. 개요 (Overview)

v2.2에서 모바일만 개편하고 **그대로 두었던 PC 화면을 이번에 전면 개편**했습니다. 이제 모바일과 PC가 같은 디자인 언어를 쓰며, 화면 폭에 따라 자연스럽게 전환됩니다.

가장 중요한 변경은 **평가 데이터 유실 버그 수정**입니다. 기존 PC 화면에서는 총평이나 좋아요를 입력한 뒤 상단 아이콘으로 나가면 저장되지 않고 사라졌습니다. "이전/다음 스타일" 버튼을 눌러야만 저장되는 구조였습니다.

상품정보 페이지는 **단품과 코디를 나란히 놓고 비교**하는 방식으로 바꿨습니다. 세로 사진 특성상 사진 한 장은 폭 600px가 한계라 남는 화면을 여백으로 버리게 되는데, 그 공간을 "옷의 디테일과 실제 착장을 동시에 판단"하는 데 쓰도록 했습니다.

아울러 **이미지 업로드 화질 문제를 근본 원인부터 해결**했습니다. 그동안 1024×1536 원본이 556×836으로 저장되고 있었습니다.

---

### 2. 평가 데이터 유실 수정 (Critical)

- **입력 후 나가도 저장됨** — 총평·선택지·좋아요를 입력하고 상단 뒤로가기로 나가도 저장이 보장됩니다. 기존에는 이전/다음 버튼을 눌렀을 때만 저장되어, 다른 경로로 나가면 입력이 사라졌습니다.
- **입력 0.7초 뒤 자동 저장** + 화면 이탈 시 즉시 저장. 저장 상태는 하단에 조용히 표시되며 성공 알림은 띄우지 않습니다.
- **타이핑 중 롤백 문제 해결** — 총평을 쓰는 도중 좋아요를 누르면 저장이 일어나면서 입력 중이던 문장이 마지막 저장값으로 되돌아가던 구조적 결함을 제거했습니다.
- 흩어져 있던 **저장 로직 5벌을 1벌로 통합**했습니다. 앞으로 저장 규칙 변경 시 한 곳만 수정하면 됩니다.
- 평가 저장 규칙에 **자동 테스트 22건**을 붙여 회귀를 방지합니다.

### 3. PC 갤러리 개편 (Major)

**① 스크롤 방식 전환**

- **페이지 넘김 제거** — 전체 스타일을 스크롤로 한 번에 탐색 (모바일과 동일)
- 상세를 보고 돌아오면 **마지막으로 본 스타일 위치로 스크롤 복원** — 어디까지 봤는지 잃지 않음
- 열 수를 **화면 폭에 맞춰 자동 산출** — 1920 화면 8열, 창을 줄이면 자동으로 줄어듦 (기존 8열 고정)

**② 진행 상태 3단계 표시**

카드 우측 상단에 스타일별 진행 상태를 글자로 표시합니다. **PC·모바일 동일 적용**입니다.

| 표시 | 의미 | 색 |
|---|---|---|
| **미조회** | 아직 열어보지 않음 | 빨강 |
| **조회 완료** | 열어봤으나 입력 없음 | 검정 |
| **평가 완료** | 총평·좋아요·선택지 중 하나 이상 입력 | 검정 |

- 진행률 집계 기준도 **"평가 완료"만 카운트**하도록 변경 — 열람만 한 것은 아직 남은 일로 표시됩니다.

**③ 좌측 사이드바 신설**

- 관리자 화면과 동일한 형태의 사이드바(홈 · 결과보기 · 로그아웃)로 이동 동선 통일
- 접기/펼치기 가능, 상태는 세션 동안 유지
- **평가결과 다운로드를 결과보기 탭으로 이동**, 공유 버튼은 제거

---

### 4. PC 상품정보 페이지 개편 (Major)

**① 단품 · 코디 2업 비교**

- 좌측에 **단품과 코디를 나란히** 배치하고 우측에 평가 패널 고정 — 디테일과 착장을 동시에 판단
- 각 사진은 **자체 화살표 · 썸네일 스트립 · 좋아요 하트**를 가짐
- 프레임을 **사진 비율에 맞춰 계산**하여 좌우 여백 0, 화면 좌우 여백 대칭
- 한쪽 종류만 있는 스타일은 자동으로 한 장 배치로 전환
- **키보드 ←/→** 로 이미지 전환 (마지막에 클릭한 사진 기준, 총평 입력 중에는 무시)

**② 배경 분리**

- 화면 바탕을 **오프화이트**로 깔고 사진·정보 카드만 흰색으로 두어, 흰 배경 상품컷이 "사진"으로 읽히도록 개선
- 기존에는 배경·프레임·사진이 모두 흰색이라 경계가 사라져 화면에 얼룩처럼 떠 보였습니다

**③ 정보 표시 정리**

- 품번을 카운터보다 크게(20px) 조정하여 위계 확보
- 스펙 값을 **좌측 정렬**로 통일하고 금액은 자릿수 고정 — 기존 가운데 정렬은 행마다 시선이 좌우로 왕복
- 빈 값은 `—` 로 표시하여 "값 없음"과 "로딩 중"을 구분
- 총평 입력창을 **내용에 맞춰 자라는 방식**으로 변경 (기존 759px 고정 → 112px 시작)
- 안내 문구를 "메모를 입력해주세요"로 변경
- 사진 위 컨트롤 정리 — "크게보기" 버튼과 이미지 순번 칩 제거(사진 클릭이 곧 확대, 썸네일이 위치 표시)
- 하단 이동 버튼에 위계 부여 — "다음 스타일"만 강조

**④ 임직원1 화면 수정**

- 원가 정보가 화면을 넘쳐 **총평 입력란의 3분의 2가 가려지던 문제** 수정 (좌우 2단 시절 규칙이 남아 행 간격을 2배로 벌리고 있었음)
- 기본정보 ↔ 상세정보 간격을 총평과 동일하게 정렬

**⑤ 창 크기에 따른 전환**

- PC에서 창을 좁히면 **개편된 모바일 화면(피드)** 으로 전환 (기존에는 개편 전 화면이 나왔음)
- 이때 **마우스가 있는 기기에서만 좌우 화살표 노출** — 스와이프가 어려운 상황을 보완

### 5. 이미지 화질 개선 (Major)

**① 원인**

업로드 시 0.5MB 상한을 맞추는 과정에서 **해상도가 깎이고 있었습니다.** PNG는 무손실 압축이라 화질을 낮춰 용량을 줄일 수 없어, 압축 도구가 쓸 수 있는 수단이 해상도 축소뿐이었기 때문입니다.

**② 조치 — JPEG 변환**

| 구분 | 변경 전 | 변경 후 |
|---|---|---|
| 저장 형식 | PNG (원본 형식 유지) | **JPEG (품질 85%)** |
| 해상도 | 556×836 | **1024×1536 (원본 그대로)** |
| 용량 | 469KB | **151KB** |

**해상도는 1.8배 올라가고 용량은 3분의 1로 줄었습니다.** 긴 변 상한도 1200px → **1600px**로 상향했습니다.

**③ 갤러리용 축소본 분리**

- 갤러리 썸네일과 상세 이미지가 **같은 파일을 쓰고 있던 문제** 해결 (165개 중 98개가 동일 파일)
- 썸네일은 **700px · 32KB** 로 별도 생성 — 갤러리 로딩 부담 대폭 감소
- 용도별 압축 기준: 썸네일 700px / 단품·코디 1600px

**④ 업로드 경로 통합**

- 압축 로직이 4곳에 흩어져 있던 것을 **공용 모듈 1개로 통합**
- **관리자 "스타일 등록" 화면은 압축이 아예 없어** 원본이 그대로 올라가던 문제 수정
- 저장 파일 확장자를 실제 형식에 맞춤 (내용은 JPEG인데 이름만 `.png`인 파일 방지)
- 투명 PNG는 흰 배경으로 합성 처리 — 상품컷 배경과 동일

> **참고**: 이번 조치는 **앞으로 업로드하는 이미지부터** 적용됩니다. 기존 165개 스타일의 이미지를 개선하려면 재업로드가 필요하며, 원본 폴더 정비 후 진행 예정입니다.

### 6. 기타 수정

- 메모 엑셀에서 **열람만 한 스타일의 빈 행 제외** — 실제 입력 내용이 있는 것만 내보냄
- 갤러리 카드 hover 그림자 대비 상향, 흰 배경끼리 붙어도 경계 식별 가능
- 상품 이미지 로드 실패 시 **자동 재시도**가 상세 페이지에도 적용 (기존에는 갤러리에만 적용되어 상세만 빈 칸으로 남았음)
- 사용하지 않던 코디 평가 페이지 경로 및 잔여 코드 제거
