# Release Notes v2.1

기간: 2026년 7월 23일
단계: 품평 동선 간소화 및 평가 기능 확장
상태: 배포 완료

# **[Showvey v2.1 릴리즈 노트]**

---

### **1. 개요 (Overview)**

품평 동선을 간소화하고 평가 수단을 확장한 업데이트입니다.
별도 단계였던 **코디평가를 상품정보 페이지에 통합**해 스타일당 품평 단계를 줄였고, 이미지 단위 **좋아요 평가**를 신설했습니다.
평가결과 리포트에는 좋아요한 이미지가 **실제 사진으로 삽입**되어 결과 확인이 직관적으로 바뀌었으며, **상품설명 항목**과 관리자 편의 기능, PLM 연동 업로드 파이프라인 전면 개편이 함께 포함되었습니다.

---

### **2. 품평 동선 개편 (Major)**

**① 코디평가 단계 통합**

- 코디평가 페이지를 별도 단계에서 제외하고, **코디 이미지를 상품정보 슬라이더에 통합 표시** (단품 → 코디 순)
- 상품정보에서 "다음 스타일" 버튼으로 바로 이동 — 스타일당 품평 동선 2단계 → 1페이지로 단축
- 코디평가 페이지 코드는 보존되어 필요 시 즉시 복원 가능

**② 상품정보 이미지 영역 강화**

- **PC 좌우 화살표**: 1024px 이상 화면에서 이미지 넘김 버튼 제공 (모바일은 기존 스와이프 유지)
- **이미지 순번 표시**: 우측 상단에 현재/전체 (예: 2/6)
- **크게보기 버튼**: 현재 이미지를 확대 팝업(핀치/휠 줌)으로 여는 명시적 버튼

---

### **3. 이미지 좋아요 평가 (Major)**

- 이미지 영역 하트 버튼으로 **보고 있는 이미지에 좋아요** — 스타일 이동 시 자동 저장, 재방문 시 상태 복원
- **하트만 눌러도 평가로 기록** (가격·총평 등 다른 항목을 입력하지 않으면 저장되지 않던 문제 함께 수정)
- 좋아요 내역은 평가 데이터(Liked_images)로 축적되어 결과 리포트에 반영

---

### **4. 평가결과 리포트 개선**

| 구분 | 내용 |
| --- | --- |
| **개별 다운로드 (갤러리)** | "좋아요 수" + "좋아요 이미지" 컬럼 추가 — 좋아요한 이미지가 **실제 사진으로 삽입** |
| **관리자 다운로드** | CSV → **엑셀(xlsx) 전환**, 좋아요 이미지 사진 삽입 |
| **속도·용량 최적화** | 이미지 6장 병렬 다운로드 + 중복 이미지 1회만 저장 + 자동 축소 삽입, 진행률 표시 |

---

### **5. 상품설명 항목 신설**

- 상품정보 페이지 기본정보에 **"상품설명" 행 추가** (전 권한 공통)
- 업로드 엑셀에 `Product_desc` 컬럼 신설 — 컬럼이 없는 엑셀을 재업로드해도 기존 설명 유지
- **작성 워크플로우 확립**: 작성양식 엑셀 자동 생성(순번/품번/이미지/원단명/혼용률 포함) → 디자인실 작성 → 일괄 반영 도구(`상품설명_쇼베이반영.bat`)로 즉시 적용

---

### **6. 관리자 기능 (Admin)**

- **단품이미지 등록 한도 확대**: 4장 → **15장** (코디 컬럼은 슬라이더 통합에 따라 정리)
- **이미지 드래그 정렬**: 품평상세 테이블에서 이미지를 끌어서 순서 변경 — 저장 시 상세페이지 표시 순서에 반영
- **테이블 성능 개선**: 이미지 지연 로딩(lazy loading) 적용 — 스타일·이미지가 많을 때의 버벅임 해소
- **갤러리 정리**: 순번 배지·품번 라벨 숨김 처리 (사진에 인쇄된 순번만 노출)

---

### **7. PLM 연동 업로드 파이프라인 (Infra & Ops)**

- **PLM 등록 순서 보존**: 다운로드 시 순서 접두어 자동 부여 — 쇼베이 표시 순서 = PLM 업로드 순서
- **견본지시서·도식화 자동 제외**: 2단계 판정(서식 의심 필터 + OCR 텍스트 밀도) — 흰 배경 소품(스카프 등) 사진 오판 방지
- **썸네일 자동 지정**: PLM 1번째 이미지 = 갤러리 썸네일 + 슬라이더 1번째
- **품번 오타 자동 보정**: 대소문자, 첫 글자 I↔1 혼동 시 정확 일치 우선으로 자동 매칭
- **순번 OCR 개선**: 세로형 제품사진 인식 오류 수정, 한 자리 숫자 확대 재시도, 파일명 순번 2차 추출
- **GitHub 동기화**: 전체 변경분 원격 저장소 반영 (커밋 `be317c2`)

### **8. 기술 스택 (Tech Stack)**

- **Frontend**: React, TypeScript, Vite, Tailwind CSS, shadcn-ui, ExcelJS
- **Backend / DB**: Firebase Authentication, Cloud Firestore, Cloud Storage
- **Hosting**: Firebase Hosting + 커스텀 도메인 (showvey.com)
- **Pipeline**: Python (RapidOCR, OpenCV, Pillow, openpyxl) — PLM API 연동 자동화
