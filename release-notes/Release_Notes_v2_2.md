# [Showvey v2.2 릴리즈 노트]

---

### 1. 개요 (Overview)

모바일 품평 화면을 **SNS 피드 방식으로 전면 개편**한 메이저 업데이트입니다.

기존 "갤러리 → 상품정보 페이지 → 다음 스타일" 의 단계 이동 방식에서, **썸네일을 누르면 이후 스타일이 아래로 계속 이어지는 세로 스크롤 피드**로 바뀌어 품평 흐름이 끊기지 않습니다. 평가 입력은 **하단 시트 하나**로 통합되어 상품정보 확인과 평가 작성을 한 화면에서 처리하며, 하단 탭바(홈·결과보기·로그아웃)로 현재 위치와 진행 상황을 항상 확인할 수 있습니다.

아울러 느린 네트워크 대비 이미지 로딩 안정화, 이미지 여백 처리 개선, 관리자 이미지 분류 도구가 함께 포함되었습니다.

**PC 버전은 기존 화면을 그대로 유지**하여, 품평은 모바일 신규 화면으로 / 회의는 기존 PC 화면으로 병행 사용이 가능합니다.

---

### 2. 모바일 피드형 품평 (Major)

**① 갤러리 → 피드 진입 구조**

- 갤러리에서 썸네일을 누르면 **해당 스타일부터 시작해 아래로 이어지는 피드**로 진입 — 스크롤만으로 다음 스타일 확인
- **양방향 무한 스크롤**: 아래로는 다음 스타일, 위로는 이전 스타일이 이어짐 (중간 스타일로 진입해도 앞쪽 확인 가능)
- 스타일 4개 단위 점진 로딩 + 화면에 가까워질 때만 이미지 로드 — 스타일 수가 많아도 초기 로딩 부담 없음

**② 갤러리 화면 개편**

- **3열 그리드**로 밀도 상향 — 한 화면에 약 9~12개 스타일 (기존 2열 6개 + 페이지 넘김)
- **페이지 넘김 제거** — 전체 스타일을 스크롤로 한 번에 탐색
- 좌측 상단 **품평 순번 표시**, 평가 완료 시 순번이 파란색으로 전환되어 남은 스타일 식별 용이
- 상단에 **평가 진행률 바 + 완료/전체 수치** 고정 표시 (스크롤해도 항상 노출)

**③ 상품정보 페이지 (게시물)**

- 이미지 좌우 스와이프 + **두 손가락 핀치 줌**으로 확대 (별도 확대 버튼 없이 사진 앱과 동일한 조작)
- 이미지 하단 **썸네일 스트립** — 등록된 전체 이미지를 한눈에 보고 원하는 이미지로 바로 이동
- 이미지 순서: **단품 이미지 → 코디 이미지**
- 상품설명은 게시물 캡션 형태로 표시 (길면 "더 보기")

---

### 3. 평가 입력 개편 (Major)

- 게시물 하단 **"상품정보 보기 · 평가 작성하기"** 를 누르면 하단 시트가 올라오며, **상품 기본정보 + 평가 입력 + 총평**을 한 화면에서 처리
- 평가 선택지는 **좌우 전환형 버튼(세그먼트 컨트롤)** 으로 변경 — 선택 상태가 즉시 식별됨
- 권한별 문항은 기존과 동일 (임직원1: 총평 / 임직원2: 가격·구매의사 / 매장: 가격·예상판매수량)
- **시트를 닫아도 입력 내용 자동 저장** — 저장 버튼을 누르지 않아 평가가 유실되는 경우 방지
- **열람만 해도 평가 완료 처리** — 평가할 내용이 없는 스타일도 확인 완료로 집계되어 진행률에 반영
- 평가를 마치면 게시물 하단이 **입력 내용 요약**으로 바뀌어, 피드를 훑는 것만으로 평가 여부·내용 확인 가능

---

### 4. 이미지 좋아요 개선

- 좋아요 대상이 **코디 이미지 → 전체 이미지**로 확대
- 이미지 우측 하단 하트 버튼 + **더블 탭 좋아요** 지원
- 좋아요 시 **화면 중앙에 하트가 떠오른 뒤 하트 버튼으로 흡수되는 모션** 적용 (SNS 방식)
- **좋아요한 이미지는 하단 썸네일에 하트로 표시** — 어떤 컷을 선택했는지 즉시 확인
- 게시물 진입 시 하트 버튼에 1회 강조 모션 — 기능 인지 유도
- 저장 방식은 기존과 동일 (Liked_images), 결과 리포트 반영도 그대로 유지

---

### 5. 하단 탭바 신설

| 탭 | 기능 |
|---|---|
| **홈** | 갤러리 / 피드 (피드에서 다시 누르면 갤러리로 복귀) |
| **결과보기** | 평가 완료 스타일 목록 + 입력 내용 요약, 행 선택 시 바로 수정 |
| **로그아웃** | 2단계 확인 후 종료 (기존 동선 유지) |

---

### 6. 이미지 표시·안정성 개선

- **로딩 표시**: 이미지가 오기 전 회색 자리 표시 — 빈 화면과 로딩 중 상태 구분
- **자동 재시도**: 네트워크 문제로 이미지 로드 실패 시 2초 → 5초 간격 자동 재시도, 이후에도 실패하면 "탭하여 다시 불러오기" 표시
- **여백 자동 채움**: 이미지 비율이 화면과 다를 때 생기는 흰 여백을 **해당 사진의 배경색으로 채워** 사진이 이어지는 것처럼 표시
- **갤러리 꽉 채움**: 잘림이 적은 이미지는 칸을 꽉 채워 표시, 크게 잘릴 이미지는 원본 유지 (옷이 잘리지 않도록 자동 판단)
- 갤러리 격자선 명도 조정 — 흰 배경 이미지끼리 붙어도 칸 구분 유지

---

### 7. 관리자 기능 (Admin)

- **코디이미지 컬럼 복원** — 품평 상세 페이지에서 썸네일 / 단품이미지 / 코디이미지를 구분해 등록
- **코디이미지 한도 확대**: 6장 → **10장**
- **단품 ↔ 코디 이동 버튼 신설** — 이미지에 마우스를 올리면 나타나는 버튼으로 재업로드 없이 분류 변경 (기존 데이터 재분류 작업에 사용)
- ZIP 일괄 업로드 시 `품번/coordi/파일명` 구조로 코디 이미지 자동 분류

---

### 8. 디자인 (Design)

- 상단 앱바·하단 탭바에 **반투명 + 배경 흐림 처리** 적용 — 콘텐츠가 비쳐 지나가는 iOS 방식
- 하트 버튼·이미지 순번 표시를 **흰 배경 + 그림자**로 통일하여 밝은 사진 위에서도 식별 가능
- 아이콘·구분선·여백 정돈, 중복 표기 제거 (품번·순번·평가 상태를 한 곳에서만 표시)
- 폰트는 기존 Pretendard 유지, 화이트 테마 유지

### 9. 인프라 및 운영 (Infra & Ops)

- **PC 버전 무변경** — 1024px 이상 화면과 관리자 계정은 기존 화면 그대로 유지, PC↔모바일 화면 전환 기능도 계속 사용 가능
- **GitHub 동기화**: 전체 변경분 원격 저장소 반영 (커밋 `ba652f4` 모바일 UI 신규 구축 → `001bf9c` 디자인 검토 반영)
